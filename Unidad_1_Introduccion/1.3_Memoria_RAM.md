# 1.3 La memoria principal (RAM)

## Visión de Bajo Nivel
A diferencia de los lenguajes de alto nivel, en Ensamblador la memoria RAM no es un contenedor abstracto gestionado automáticamente. El programador debe interactuar con ella estructurándola mediante una técnica arquitectónica llamada **Segmentación**.

## La Segmentación en x86
La segmentación organiza la memoria dividiéndola en bloques lógicos especializados, garantizando orden y seguridad básica en la ejecución. Los segmentos críticos son:

* **Segmento de Código (CS - Code Segment):** Almacena exclusivamente las instrucciones del programa traducidas a lenguaje máquina. El procesador extrae de aquí qué es lo que debe hacer a continuación.
* **Segmento de Datos (DS - Data Segment):** Contiene las variables estáticas, globales y estructuras de datos declaradas por el programador.
* **Segmento de Pila (SS - Stack Segment):** Área dinámica (LIFO) vital para el almacenamiento de variables locales, parámetros de funciones y direcciones de retorno durante la ejecución del programa.

## Direccionamiento Lógico: Segmento:Desplazamiento
Para localizar un dato exacto en la memoria, el procesador no usa una dirección lineal simple, sino un par de coordenadas `Segmento:Desplazamiento` (Segment:Offset).

* **Analogía del Hotel:**
    * **Segmento:** Define la dirección base o el inicio del bloque (Ej. "Piso 4" del hotel).
    * **Desplazamiento (Offset):** Define la distancia exacta en bytes a partir de esa dirección base (Ej. "Habitación 12" en ese piso).
* **Ejemplo Técnico:** Una dirección como `CS:0100h` indica que la instrucción a ejecutar está en el Segmento de Código, ubicada a 100 bytes en formato hexadecimal desde el inicio de dicho segmento.
